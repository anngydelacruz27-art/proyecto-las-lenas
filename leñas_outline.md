# Estructura E-commerce Leñas

## Páginas Principales

### 1. index.html - Catálogo Principal
- Hero section con imagen de parrilla peruana
- Buscador de productos
- Filtros por categoría (Parrillas, Chifa, Comida Rápida)
- Grid de productos con precios, ratings y botón de agregar
- Carrito flotante

### 2. cart.html - Carrito de Compras
- Lista de productos seleccionados
- Control de cantidades
- Cálculo de subtotal, impuestos y total
- Aplicación de cupones de descuento
- Botón de proceder al checkout

### 3. checkout.html - Proceso de Pago
- Formulario de información del cliente
- Métodos de pago peruanos (Yape, Plin, Tarjetas)
- Confirmación de pedido
- Generación de número de tracking

### 4. tracking.html - Seguimiento de Pedido
- Estado del pedido en tiempo real
- Mapa de ubicación del repartidor
- Tiempo estimado de llegada
- Historial de estados

## Elementos Comunes
- Navegación superior con logo Leñas
- Buscador de productos
- Carrito con contador
- Footer con información de contacto
- Sistema de notificaciones
